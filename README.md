# ☕ Coffee UI Clone

A responsive Starbucks-inspired UI clone built using HTML and Tailwind CSS.  
This project focuses on modern UI design and responsive layout.

---

## 🚀 Features
- Responsive design (mobile + desktop)
- Built with Tailwind CSS
- Mobile menu toggle using JavaScript
- Clean and modern UI layout

---

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS
- JavaScript
